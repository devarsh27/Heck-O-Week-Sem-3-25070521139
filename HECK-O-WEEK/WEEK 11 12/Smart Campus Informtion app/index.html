ABOUT THE PROJECT

One Portal. Better Campus Awareness.

Campus360 is a student information portal concept designed to organize campus announcements, academic resources, and student activities in one accessible interface.

The project demonstrates HTML, CSS, JavaScript, asynchronous programming, browser events, API integration, and local storage.
